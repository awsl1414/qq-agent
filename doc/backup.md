# 备份与恢复

在设置页的备份面板中，可以把选中的数据保存到本地目录、WebDAV 或 S3 兼容存储，也可以直接导出一份离线副本。数据目录的位置见 [运行方式与部署第 3 节](running.md#3-数据目录)。

## 1. 备份哪些内容

每个目标可以分别选择内容；「本地导出内容」有独立的选择。以下为实际支持的 13 类，除「锻造台草稿」外默认勾选。没有数据的类别会跳过并说明原因；全部为空时不会生成空备份。

| 类别 | 内容与边界 |
|---|---|
| 会话存档 | `messages/` 中的聊天记录；不包含 `sessions/` 的 Agent 处理过程卡片 |
| 群友印象 | `memory/` 中的成员印象；不打包 `memory-v3/` 派生索引 |
| 用量统计 | `usage-daily.json`、`usage-archived-days.json`、`usage-today.json`，不含逐条用量账本 |
| 提醒 | 待触发的提醒事项 |
| 表情配置 | 表情索引 `stickers.json`；不含插件私有存储里的素材本体 |
| 壁纸 | 静态壁纸、壁纸状态、导入记录和用户背景图 |
| 桌宠 | 模型、预览图和状态 |
| 人设 | 全局人设、会话独立人设及统一人设设置 |
| 自定义人设库 | 用户保存的自定义人设 |
| 名单 | 允许、拒绝、屏蔽及社区豁免名单 |
| 工具与插件配置 | 工具和扩展的开关及配置；排除顶层 API、协议端、服务端等敏感配置和账号池技能配置 |
| 用户扩展 | 用户安装的插件与技能文件，不含内置扩展及一般插件私有数据 |
| 锻造台草稿 | 尚未安装的扩展草稿、快照与来源记录；默认不勾选 |

这不是整个数据目录的镜像：日志、缓存、登录态、社区账号、一般 `plugin-data/` 私有存储和备份密钥派生文件不随上述类别打包。「包含密钥」会额外加入去掉备份目标配置后的 `config.json`，并强制加密。

## 2. 设置备份目标

在「添加备份目标」选择方式，填写名称、连接信息，启用目标并勾选备份内容，点击「保存备份设置」，再「测试连接」。已有凭据字段留空表示保留原值；WebDAV 密码和 S3 Secret Access Key 加密保存在本机配置中。

| 方式 | 适用场景 | 填写项 |
|---|---|---|
| 本地目录 | 本机副本、移动硬盘或局域网共享盘 | 可写目录路径；桌面端可点「浏览…」。网页模式填写的是运行 QQ Agent 那台机器上的路径 |
| WebDAV | 支持 WebDAV 的 NAS、Nextcloud 或网盘 | WebDAV URL、用户名、密码；信任的自签证书服务需开启「允许不安全 TLS」 |
| S3 兼容 | 对象存储或自建 MinIO | S3 Endpoint、Region、Bucket、Access Key ID、Secret Access Key、Path style；Region 默认 `us-east-1`，应以服务商要求为准 |

备份文件放在目标的 `qq-agent/` 路径下，文件名为 `backup-<时间>-<随机后缀>.qqab`。S3 的 Bucket 需事先准备好。WebDAV / S3 的连接测试通过后，再做一次「立即备份」确认实际写入成功。

「立即备份」将数据写入所有启用的目标，每个目标只收到自己勾选的类别；界面会分别报告成功和失败。打开「定时备份」后按间隔执行，应用需要保持运行。默认间隔为 24 小时、保留 7 份；保留策略只清理符合本功能文件命名规则的旧备份。删除目标配置不会删除目标里已有的文件。

## 3. 加密与本机实例限制

当前界面通过「包含密钥」开启整包载荷加密，没有独立的加密密码输入框。确认开启后，备份会包含 API Key、访问令牌等敏感配置，并使用 AES-256-GCM 加密载荷；外层清单仍可看到类别、路径、大小等元信息。

**密钥由本机身份与当前数据目录的 `backup-crypto.salt` 派生，加密备份包不能跨机器解密。** salt 不会装进备份包；不要删除或重新生成它。即使仍在同一台机器，丢失 salt、改用新的数据目录或机器身份变化，也可能无法恢复原来的备份。

**未开启「包含密钥」的备份也带有本机实例 HMAC 认证，因此同样不能直接在另一台机器或另一实例恢复。** 「导出到本地」使用相同的备份格式与认证规则。此功能用于本实例恢复；跨机器迁移不要把关闭加密当作解除限制。

## 4. 恢复流程

恢复分为查看预览、确定恢复范围、执行导入三个阶段。当前界面与接口的能力有一处差异：**恢复接口支持选择类别，但备份面板尚未提供类别勾选控件**；面板中的「执行恢复」会按包内可恢复内容使用默认选择。如果只需要部分内容，应使用预先按所需类别生成的备份，或等待界面补齐选择功能，不要在确认框中寻找不存在的选项。

1. 在备份面板点击「刷新备份列表」，找到目标下的备份，点击「预览与恢复」。程序先验证包的认证与完整性，必要时解密，再展示来源内容和本机数据的预览。
2. 检查预览中的类别、会话、数据量及扩展列表，确认这些就是需要导入的范围；不符合预期时取消。当前面板确认后按默认选择导入，不能在这一步逐类勾选。
3. 点击「执行恢复」。**导入前自动生成可回滚快照**，保存在当前数据目录的 `import-backups/` 下；数据通过既有导入流程合并或覆盖，消息默认合并去重。
4. 恢复完成后检查结果。用户扩展先进入锻造台暂存并做安全检查，需要逐个「确认安装」，安装后默认关闭；不会仅因恢复就自动启用。
5. 需要撤销时，在「恢复回滚」选择对应快照。回滚会还原相关文件，也会撤销恢复后对这些文件的修改。

目前面板从已配置目标列出备份，没有直接上传本地导出 ZIP 的恢复入口。需要直接通过界面完成恢复时，建议配置「本地目录」目标并使用「立即备份」，再从该目标列表恢复。

## 5. 「导出到本地」与「备份到目标」

| 操作 | 内容选择 | 文件去向 | 历史与保留策略 |
|---|---|---|---|
| 导出到本地 | 展开「本地导出内容」单独勾选，无需配置目标 | 桌面端弹出保存对话框，网页模式下载 ZIP；不上传到备份目标 | 不计入备份历史，不执行目标保留策略 |
| 备份到目标（「立即备份」或定时备份） | 按每个启用目标已保存的类别选择 | 本地目录、WebDAV 或 S3 目标中的 `.qqab` 文件 | 记录运行结果，成功写入后按保留份数清理旧包 |

本地导出的 ZIP 仍是备份包，受第 3 节的本机实例认证限制；其恢复入口限制见第 4 节。

## 6. 常见问题

| 现象 | 处理方式 |
|---|---|
| WebDAV 自签证书连接失败 | 对确认可信的服务开启「允许不安全 TLS」，保存后重试；该选项会跳过证书验证 |
| MinIO 等自建 S3 连接或写入失败 | 开启 Path style，检查 Endpoint、Region、Bucket 和密钥权限；当前新目标默认开启 Path style |
| 提示没有启用目标 | 添加目标并启用、保存；只想留一份文件时可直接「导出到本地」 |
| 提示没有可备份内容 | 选中的类别都没有数据；检查类别旁显示的体积，待有数据后再备份 |
| 部分目标失败 | 检查逐目标错误；已有成功副本不表示每个目标都成功 |
| 提示包损坏、被篡改或不属于本机实例 | 核对是否为原机器、原实例以及原 `backup-crypto.salt`；换机或丢失 salt 不能靠重新输入目标密码解决 |
| 本地导出后历史没增加、列表找不到 ZIP | 这是当前行为：导出不记录历史，目标列表只识别规定命名的 `.qqab`；使用本地目录目标备份可从列表恢复 |
| 大壁纸 / 桌宠模型备份失败 | 单文件上限 64 MiB、收集总量上限 512 MiB、成包上限 256 MiB；按错误提示减少类别或文件体积，程序不会以静默丢文件的方式生成“成功”备份 |
