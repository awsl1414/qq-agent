# Live2D 桌面伙伴（desktop-pet 1.3.7）

QQ Agent 的确定性插件。它需要 Electron 窗口支持，在控制台里占一个「桌宠」页。
桌宠的行为由程序状态和你的点击触发，不注册任何群聊发送工具。它不会自己在群里说话。

## 页面里有什么

「桌宠」页分四块：

- **角色与显示**：已有角色卡片、缩略图与使用状态，一键切换。显示/隐藏、导入 `.model3.json`、
  大小、透明度、置顶、穿透、视线追踪、位置锁定。
- **动作控制台**：真实动作与表情，随机动作/表情/坐站三个独立开关，活动状态、预览回执与失败原因、
  权重、间隔、点击冷却、状态映射。
- **屏幕陪伴**：复用已有的模型 API 目录与密钥，自动观察开关、手动观察、停止请求、多屏选择、
  用量与最近回复。
- **生活与成就**：陪伴日期、有效时长、互动次数、时段与场景分布，六项成就与进度。

## 交互

点角色触发互动，回应动作开始后显示一个本地气泡，**不调用 AI**。
双击不会打开 QQ Agent。重复点击受互动冷却限制。按住角色可拖动。
右键菜单里的「打开桌宠控制台」是显式设置入口。开启穿透后，回「桌宠」页关掉穿透即可恢复鼠标交互。

文字气泡按内容自动调整大小，没有内部滚动条，支持选择复制、关闭按钮和 Esc；
悬停、选中文字或聚焦阅读时暂停自动消失。1.3.7 把气泡放在独立的透明窗口里，
所以回复出现、换长短、关闭都不会移动或缩放角色窗口，思考动作照常播放。
「预览文字气泡」只显示本地示例，不截图、不调模型。角色首次加载后生成透明缩略图，
缓存在 `desktop-pet/previews/`；没用过的角色显示占位提示。

## 细节

气泡参照 DaiMeow 头顶的白色圆角样式，普通回复约 6 秒后用 0.3 秒淡出。
随机动作默认 5–20 秒一次；DaiMeow 坐站 60–120 秒，70% 站、30% 坐，站姿 21 个动作、坐姿 17 个。
特殊动作的道具轨迹与显隐已移植，普通角色沿用通用逻辑。模型动作元数据按真实文件识别，
兼容导入后重命名的分组。

同一个动作手动 FORCE 重播时先预加载，再处理 SDK 0.4.0 对 current/reserved 同组同索引的拒绝；
预览要收到 renderer 回执才算成功。隐藏、停用、重载、切换、关闭都会取消等待并清理叠加层。
`runtime.animation` 是本次运行的轻量诊断，不写进聊天或观察历史。

首次没有角色时会安装一个官方示例模型，已有角色不会被覆盖。换角色时选完整导出文件夹里的
`.model3.json`，保持模型、贴图、动作的相对路径。只接受本地模型资源，不执行模型包里的代码。

## 屏幕观察

自动观察默认关闭。开启后默认每 30 秒检查一次，画面变化小时跳过模型请求，180 秒无操作暂停。
默认上限每小时 60 次、每天 200 次，可在页面改。手动观察只防并发重复点击，不受这套次数限制；
上游 API 的限额和费用照旧适用。停止会取消本机等待和迟到的回复，上游已经开始处理的请求是否计费
由服务商决定。

截图只在请求内存里处理，不写历史文件。文字回复、场景、模型和 Token/估算费用存在
当前数据目录的 `desktop-pet/state.json`。截图会发给所选模型 API，回复显示在本地桌面，
不会自动发到 QQ。

角色能做什么取决于模型本身。随包自带的 DS鼠控版 有 8 个动作组和 44 个表情；
站坐这类专属姿态只有模型本身提供了相应动作或表情时才能用。
