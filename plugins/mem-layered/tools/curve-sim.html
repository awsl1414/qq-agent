分层记忆（增强版）· 遗忘曲线与记忆曲线

曲线不是画的示意图，是按 lib/store.js 的式子逐点复算的。 命中只改 score 与 S，有效权重是派生值， 淘汰要「够老」和「权重低」同时成立。

模型假设：一块被创建后，每隔固定天数被检索命中一次（现实中是否命中取决于有没有人问到相关的事）。 每轮自动检索、模型主动调检索工具、以及 30 分钟的重复注入冷却，共同决定这个间隔。 注意自动注入只记「被动命中」、不加权重，所以真正会喂胖权重的只有模型主动调检索工具那一条路。

// 派生值：不写回，所以衰减不会被重复施加
effectiveScore = clamp(score, 0.05, 3) × 0.5((距上次命中天数 / S)q)
// 命中：增益看间隔，S 自己会长（间隔重复效应）
r = min(4, log2(1 + 间隔天数 / S))
score = clamp(score × (1 + (hitBoost - 1) × r), 0.05, 3)
S = clamp(S × (1 + stabilityGain × r), 1, 3650)   lastHitAt = now
// 淘汰：两个条件必须同时成立
块年龄 ≥ forgetAfterDays  且  effectiveScore ≤ minForgetScore

图一 · 遗忘曲线（从不被想起）

块创建后一直没被检索命中，权重按 0.5^((t/S)^q) 衰减；曲线在实心菱形处中断，代表块文件被删除。 删除之后那条水平虚线是梗概墓碑：细节没了，但「我好像记得有这么回事」还在，仍能被检索到（命中时还会按 id 区间从原文把整块重建回来）。

图二 · 记忆曲线（被周期性想起）

每次命中按间隔加分并让 S 变长，于是锯齿的谷底越来越高、衰减越来越慢。间隔越短，抬升越快。
